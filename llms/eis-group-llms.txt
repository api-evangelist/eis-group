# EIS Group

> EIS Group (EIS Software Limited / EIS Ltd) is a San Francisco, California core-systems vendor for insurance, founded in 2008 out of Exigen Insurance Solutions. EIS sells the EIS Platform and EIS OneSuite — a cloud-native, microservices core suite covering customer management, policy administration, billing, and claims — across group benefits, property and casualty / general, protection, life and annuities, and pet insurance. EIS markets itself as API-first and is a certified MACH Alliance member, but its API surface is not public: there is no self-serve developer portal, and docs.eisgroup.com answers HTTP 401 behind an HTTP Basic realm named "EIS Group Users".

## API access

- [Documentation (gated)](https://docs.eisgroup.com/): HTTP 401 on every path; `WWW-Authenticate: Basic realm="EIS Group Users"`. Customer/partner login wall, not a developer portal.
- [Partner application](https://www.eisgroup.com/company/partner-application/): the actual route to API access — API documentation, sandbox, and credentials are granted through a licensed implementation or a partner agreement.
- [Partners](https://www.eisgroup.com/company/partners/): PwC, EY, Accenture, AWS, Azure, IBM.
- No OpenAPI, Swagger, AsyncAPI, GraphQL SDL, .proto, or public Postman collection is retrievable. `developer.`, `developers.`, `api.`, `apidocs.`, `portal.`, `sandbox.` on eisgroup.com do not resolve.
